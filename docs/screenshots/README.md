# Synthetic UI evidence

These screenshots were captured from the local built default example using `pnpm test:ui`. They show an invented business, generated SVG illustrations, reserved fictional contact details and a local-only React form simulation.

- `home-desktop.png`: desktop home page.
- `home-mobile.png`: 390px home page and sticky contact bar.
- `form-invalid.png`: validation feedback.
- `form-success.png`: explicit local simulation confirmation.
- `form-offline.png`: offline feedback.
- `not-found.png`: 404 state.

No live website, real customer data or third-party media is represented. The browser suite writes fresh screenshots to ignored `artifacts/ui/`; selecting screenshots for documentation is an intentional review step.
